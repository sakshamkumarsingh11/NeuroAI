Section 01

Project Vision & Goals

Traumatic Brain Injury (TBI) and stroke frequently leave patients with severe motor, speech, and cognitive deficits requiring repetitive, long-term, personalised rehabilitation. Traditional systems fall short in four critical ways:

Therapist Scarcity

High-frequency professional sessions are inaccessible for most patients due to cost and scheduling.

Subjective Tracking

Progress is measured by observation alone — no granular, objective clinical data.

No Personalisation

Static exercise sheets cannot adapt to a patient's daily performance, causing frustration or boredom.

Slow Diagnostics

Radiologists need fast, explainable tools to screen CT scans for intracranial hemorrhages.

The platform addresses each of these with an integrated AI-driven ecosystem:

🧠
Early Detection & Explainability Rapid CT scan classification with Grad-CAM visual overlays that highlight the exact brain regions triggering the prediction.
🎙️
Objective Speech Therapy Patient speech is transcribed into phonemes (fundamental sounds), then scored algorithmically — removing clinical subjectivity.
🤖
Intelligent Difficulty Adjustment A Reinforcement Learning therapist (PPO) dynamically scales exercise difficulty based on accuracy, fatigue, and recovery trend.
👁️
Real-time Facial Monitoring MediaPipe tracks lip closure, jaw movement, and facial asymmetry during exercises — key indicators of TBI-induced muscle weakness.
🖥️
Patient & Doctor Portals Clean React interfaces for conducting exercises, reviewing progress graphs, and booking consultations.

Section 04

CT Scan Analysis Backend

Located in ./backend/ — classifies head CT scans for Intracranial Hemorrhage (ICH).

🧩

ML Model — model.py & predict.py

EfficientNet-B4 fine-tuned for multi-label hemorrhage detection

Backbone
EfficientNet-B4
Pre-training
ImageNet transfer
Output classes
5 hemorrhage types
Activation
Sigmoid (0.0 → 1.0)

Classifier head: Dropout(0.4) → Linear(512) → BatchNorm → ReLU → Dropout(0.3) → Linear(5)

Decision thresholds per class: [0.45, 0.5, 0.5, 0.45, 0.45]

The 5 detected hemorrhage sub-types:

EDH

Epidural — Bleeding between the skull bone and the outer membrane (dura mater).

IPH

Intraparenchymal — Bleeding directly inside the brain tissue.

IVH

Intraventricular — Bleeding inside the brain's fluid-filled chambers (ventricles).

SAH

Subarachnoid — Bleeding in the space surrounding the brain, beneath the arachnoid membrane.

SDH

Subdural — Bleeding between the dura mater and the arachnoid membrane.

🔥

Explainability — Grad-CAM (gradcam.py)

Generates heatmap overlays so clinicians can see why the model flagged a region

1

Hook Activation — Forward hooks on model.backbone.features[-1] extract the final convolutional feature maps.

2

Hook Gradients — Backward hooks capture gradients for the predicted class during backpropagation.

3

Weight Calculation — Gradients are averaged spatially (global average pooling) to obtain importance weights per feature map.

4

Heatmap Generation — Weighted activation sum → ReLU filter → resize to 224×224 → cv2.COLORMAP_JET colour map applied.

5

Overlay — Blends greyscale CT scan with coloured heatmap. Red/yellow = high attention (suspect lesion), blue/green = low attention.

Speech Therapy Backend

Located in ./tbi_therapy (1)/tbi_therapy/ — orchestrates speech sessions, facial monitoring, RL planning, and result storage.

🎤

Speech Analysis Pipeline — speech_analysis.py

4-stage phoneme transcription and scoring pipeline

Stage 1
Allosaurus
Audio → raw IPA phonemes
[ɹ, e, d]
→
Stage 2
IPA → ARPAbet
Maps to CMU dict format
[R, EH, D]
→
Stage 3
Phoneme Folding
61 TIMIT → 39 classes
dialect tolerance
→
Stage 4
Edit Distance
Levenshtein DP
Accuracy = Cp/Tp × 100%

Why Allosaurus? Standard speech engines fail for TBI patients because of dysarthria (slurred/distorted speech). Allosaurus is an unsupervised multilingual model that extracts raw phonemes directly — bypassing vocabulary matching entirely.

Phoneme Folding ensures minor dialect differences (e.g. /aa/ vs /ao/ mapped to the same bucket) don't unfairly penalise patients. Score formula: Accuracy = (Correctly aligned phonemes / Total reference phonemes) × 100%

🧬

Reinforcement Learning Planner — rl_planner.py

PPO Actor-Critic agent that behaves like a live adaptive therapist

State Space (5 inputs)

  • Severity level (Severe→Normal, normalised 0–1)
  • Recent accuracy (avg phoneme accuracy, last few attempts)
  • Accuracy trend (improvement vs decline vs previous session)
  • Session count (total sessions practiced)
  • Fatigue proxy (derived from pause ratio in patient speech)

Action Space & Rewards

  • 0 — Easier: decrease difficulty 1 level
  • 1 — Same: maintain current level
  • 2 — Harder: increase difficulty 1 level

Reward signals:
+reward for pronunciation improvement
+1.0 for maintaining high accuracy at harder level
−1.5 if accuracy drops below 40% after advancing
−0.5 if patient exits early/gives up

Therapy Difficulty Levels:

Level 0 · Severe
Sustained Vowels & CV Syllables
"pa", "ma", "ta", /a/, /i/, /u/
Level 1 · Moderate
Multi-syllables & Minimal Pairs
"butter", "coffee", pat/bat
Level 2 · Mild
Conversational Sentences
"I would like a cup of tea"
Level 3 · Normal
Open Storytelling & Debate
Free-form discourse prompts

💾 RL model weights auto-save to ./models/ppo_actor.pt and ./models/ppo_critic.pt after every session — patient difficulty policies persist across program runs.

👄

Facial Feature Analysis — facial_analysis.py

MediaPipe Face Landmarker monitoring during speech exercises

👄

Lip Closure Score — Measures upper-to-lower inner lip distance. If lips stay open during sounds that require closure (e.g. /p/, /m/), it flags reduced motor strength.

↕

Jaw Vertical Position — Compares chin coordinates to forehead baseline. Checks whether jaw range of motion is normal or constricted.

⚖

Facial Asymmetry — Calculates relative horizontal difference of left/right symmetry pairs (mouth corners, eye corners, cheeks) relative to facial midline. High asymmetry = facial droop from unilateral stroke/TBI.

Section 07

Setup & Run Instructions

Each of the three modules starts independently. Open three separate terminals.

3000React Frontend
8001CT Scan Backend (FastAPI)
5000Speech Backend (Flask)

Prerequisites: Python 3.9–3.11, Node.js, and ffmpeg installed and in system PATH (ffmpeg is required by Librosa to parse .webm audio from browsers).

1

CT Scan Backend

./backend/ · FastAPI · Port 8001
1

Open a terminal in the ./backend/ folder and create a virtual environment:

python -m venv venv
# On Windows:
.\venv\Scripts\activate
2

Install dependencies:

pip install -r requirements.txt
3

Verify best_model.pth exists inside ./backend/ — this file holds the trained EfficientNet-B4 weights. The server will fail to start without it.

4

Start the FastAPI server:

uvicorn app:app --host 127.0.0.1 --port 8001

Swagger API docs available at: http://127.0.0.1:8001/docs

2

Speech Therapy Backend

./tbi_therapy (1)/tbi_therapy/ · Flask · Port 5000
1

Open a terminal in the ./tbi_therapy (1)/tbi_therapy/ folder and create a virtual environment:

python -m venv venv
# On Windows:
.\venv\Scripts\activate
2

Install dependencies:

pip install -r requirements.txt
3

Download the CMU Pronouncing Dictionary to the ./data/ directory:

# PowerShell:
New-Item -ItemType Directory -Force -Path .\data
Invoke-WebRequest -Uri "https://svn.code.sf.net/p/cmusphinx/code/trunk/cmudict/cmudict-0.7b" -OutFile ".\data\cmudict-0.7b"
4

Place the MediaPipe model file face_landmarker.task inside the ./models/ directory.

5

Initialise the SQLite database:

python -c "from modules.session_manager import init_db; init_db()"
6

Start the Flask server:

python app.py

Server starts at: http://127.0.0.1:5000

3

React Frontend

./frontend/ · Port 3000
1

Open a terminal in the ./frontend/ folder and install packages:

npm install
2

Ensure the .env file is configured with the correct base URLs:

REACT_APP_API_URL=http://localhost:8000/api/v1 REACT_APP_VOICE_API_URL=http://localhost:5000 REACT_APP_CT_SCAN_API_URL=http://localhost:8001
3

Start the development server:

npm start

Open http://localhost:3000 — grant microphone and camera permissions when prompted.

Section 08

Tips, Troubleshooting & Extensibility

🔧

Speech Prediction Failure

If speech analysis returns an error, verify ffmpeg is in your system PATH. It is required by Librosa to decode .webm audio uploaded from modern browsers.

📝

Adding New Therapy Words

Edit the THERAPY_PROTOCOLS dictionaries in modules/severity.py. Word lists are dynamically picked based on the current active difficulty tier.

🤖

RL Model Persistence

Actor/critic weights are auto-saved to ./models/ppo_actor.pt and ./models/ppo_critic.pt after every session — patient policies persist across restarts.

🩺

CT Model Weights

The file best_model.pth in ./backend/ is required for the CT backend to start. Confirm it exists before launching Uvicorn.

📷

Browser Permissions

The frontend requires both microphone and camera access. On first load, the browser will prompt for permissions — allow both for speech and facial analysis to work.

📖

API Documentation

FastAPI auto-generates interactive Swagger docs at http://127.0.0.1:8001/docs — useful for testing CT scan endpoints directly without the frontend.
